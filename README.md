# PRANREKHA: Every Signal Matters

### Astronaut Health Monitoring Platform

**PRANREKHA** is an interactive software prototype designed to organise and monitor astronaut health data during space missions.

## Our Mission
To develop an integrated health-monitoring platform that helps track, understand and visualise the effects of spaceflight on astronaut wellbeing.

## Key Features
- Astronaut health monitoring dashboard
- Health data entry and mission-specific records
- Microgravity Impact Explorer
- Six dimensions of spaceflight-related health effects
- Optional menstrual-health tracking
- Interactive mission timeline
- Health reports and data export

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## Project Team
Team PRANREKHA

## Important Note
This is an educational prototype using illustrative sample data. It is not a certified medical monitoring system and is not connected to live spacecraft sensors.
